Designed for AI Coding Assistants and Multi-Agent Orchestration Platforms including **Claude Code**, **Cursor**, **GitHub Copilot**, **Gemini**, **Windsurf**, **Codex**, **Amp**, **RooCode**, **Android Studio / Gemini AI**, and custom MCP/agent workflows.

## 🛠️ Antigravity Skills Manager CLI

Manage and validate skills using the embedded CLI platform:

```bash
# Navigate to the CLI manager directory
cd antigravity-skills

# List available skills & categories
python skills_cli.py list

# Search for a specific skill
python skills_cli.py search "security"

# Validate skill formatting and schema compliance
python scripts/validate-skills.py

# Build/refresh the master catalog
node scripts/build-catalog.js
```

## 🤖 Agent & Platform Integration

This repository is pre-configured to work seamlessly with various AI developer environments:

### Claude Code & Anthropic Agents
Load skills directly by referencing the `SKILL.md` paths in your prompts or system instructions.

### Cursor / Windsurf / Copilot / RooCode
Include skill instructions in your project's `.cursorrules`, `.windsurfrules`, or system prompt files.

### Android Studio & Jetpack Compose AI
Integrate skills with Android Studio AI assistant by placing skills in your project workspace or global AI config folder.
